# Strict Adherence and Ingestion Order Protocol

## 1. Unbreakable Sequence of Ingestion

When you receive a command to execute an algorithm, workflow, or regulated task (e.g., `/derive`, `/test`, `/document`), you MUST strictly comply with this temporal reading sequence. You are FORBIDDEN from reversing the hierarchy:

1. **Phase Alpha - Framework Ingestion:** Use your tools to locate and read all relevant instructions stored within the `.agent/` directory (workflows, skills, templates associated with the task). 2. **Phase Beta - Tabula Rasa Purge:** Proactively eliminate temporary artifacts or trash from your workspace (for example, by cleaning `.agent/scratch/` or discarding residual files in your environment) generated by previous executions of the same command.
3. **Phase Gamma - Environment Diagnostic (Only if Rule 04 is active):** Execute the hygiene leveling (`MASTER-SPEC`, `TODO.md` placeholders) if they are missing.
4. **Phase Delta - Contaminated Reading:** ONLY AFTER assimilating the algorithm are you authorized to invoke tools to peek into and read the user's concrete project files (code, living documents, database).

## 2. Cognitive Isolation vs. Additive Expansion

When entering Phase Delta to read pre-existing specification documents (e.g., `MASTER-SPEC.md §8`), you must formatively evaluate your approach:
- **Structural Amnesia:** If the previous documents lack the canonical taxonomy or are in an obsolete format, apply "Categorical Blindness." Extract the empirical value but ruthlessly destroy and replace the format in your output.
- **Additive Expansion (Nuance):** If the previous documents **already** possess canonically valid records (e.g., checks like `[ACTOR.CAT.NN]`), you MUST read them with extreme attention. Your mission in analytical workflows (like `/derive`) is not to destroy them, but to generate purely **ADDITIONAL AND NON-OVERLAPPING** nodes (MECE). 

**The "No-Op" Trap:** If the file already has 18 perfectly formatted checks, and your mathematical algorithm detects actor cross-references that derive 140 new checks... **YOU MUST NEVER BE LASSITUDINOUS**. The fact that the document "already looks full" is no excuse to halt the algorithm. Accumulate and interleave the new mathematical density while respecting what already exists. Ignoring this is a Critical Execution Failure.
